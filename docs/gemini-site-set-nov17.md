# Site image set, Nov 17 2026 evening

Dourado asked for more imagery across the whole site, starting with the Clinicians page, which has no photos at all. Ten Gemini images, in the order below. The Clinicians page goes first.

## How to run each one

1. Open gemini.google.com, start a new chat for each image, switch on Images, keep 3.1 Pro.
2. Set the Aspect ratio the block names. Ask for the largest size offered.
3. Attach a file only when the block says so. Otherwise attach nothing.
4. Paste the block.
5. Check it against the reject list at the bottom before you download.
6. Download it, rename it to the name in the heading, and drop it in the Velacore Health folder under `assets-in`, then `lifestyle`, or `products` for the two vial pairs.
7. Tell Vale "convert the images". Vale checks every image enlarged, makes the phone and desktop sizes, places them, and sends them through vc-reviewer.

You never need to resize anything. Vale makes a 1600 wide desktop copy and a smaller phone copy from each one.

## Reject the image if

- Any hand has more or fewer than five fingers, or there is an extra hand or arm.
- Any readable word, number or logo appears outside a vial label.
- A vial label changes, misspells or adds a word.
- A name badge, certificate, ID card or lanyard appears.
- Scrubs are pine green.
- Anything in the never list shows: pills, needles, syringes, scales, tape measures, mirrors, gym gear.
- The skin looks glossy or airbrushed.

When one fails, reply in the same chat with the one thing to fix, for example "same image, but the left hand must have exactly five fingers".
